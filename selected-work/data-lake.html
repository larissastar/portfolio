Data Lakehouse

I led design for the OCI (Oracle Cloud Infrastructure) Data Lakehouse experience, collaborating closely with product, engineering, and architecture teams to define key workflows and user needs through competitive analysis and persona development. I produced a large volume of high-fidelity designs and led formal design reviews to shape the MVP, while also identifying key gaps and opportunities for future improvements. Learn more

User Problem and Personas
User Problem

Users struggle to find and work with data because it is spread across multiple systems and formats, requiring them to switch between tools. This fragmentation slows decision-making and makes it hard to trust the data. It also complicates access control, with permissions and roles managed across different systems. Users need a unified, intuitive way to explore and analyze data, with clear and consistent governance.

KEY INSIGHTS

Through this project, we learned that a unified data lakehouse experience significantly reduces the friction users face when working with data spread across multiple systems. The ~400 screens and high-fidelity prototype provided a solid foundation for the MVP, while formal design reviews helped align stakeholders and prioritize features. Post-MVP opportunities identified include deeper integrations, enhanced governance controls, and more intuitive data exploration tools to further empower users in their data journey.
